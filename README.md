## 👋 About me

I'm an **AI/ML and full-stack developer**. I like projects where a model has to prove itself against a real benchmark: my chess engine plays against calibrated Stockfish levels, and my microplastics classifier is judged on held-out spectra. On the web side I build typed, tested APIs and fast static front ends.

- 🧠 Currently deepening: **reinforcement learning, MCTS and model evaluation**
- 🔬 Applying ML to **life-science problems** (FTIR spectra, polymer identification)
- 🌐 Building web apps with **FastAPI + PostgreSQL** back ends and **Astro + TypeScript** front ends
- ♟️ Plays on Lichess with a bot I trained myself
